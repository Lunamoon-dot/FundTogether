archive **không phải yêu cầu sản phẩm hiện hành**.

| Nhóm | Nội dung lịch sử |
| --- | --- |
| [legacy-reward](legacy-reward/README.md) | Reward vật lý và invariants đã bị thay thế cho campaign mới |
| [organizations](organizations/README.md) | Organization-owned charity/campaign workflow |
| [milestones](milestones/README.md) | Milestone disbursement và evidence timeout cũ |
| [refunds](refunds/README.md) | Refund/recovery của baseline cũ |
| [old-workflows](old-workflows/README.md) | Các bước backend, manual test và đề xuất không còn là current direction |

Khi trích dẫn archive, phải ghi rõ đây là bằng chứng lịch sử hoặc regression,
không suy diễn thành quyền, trạng thái hay money flow của Campaign.
